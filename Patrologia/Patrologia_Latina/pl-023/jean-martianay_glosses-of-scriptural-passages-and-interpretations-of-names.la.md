# Glosses of scriptural passages and interpretations of names

**Author**: Jean Martianay  
**Series**: PL 23  
**Columns**: 23–1554D  

[23] {#pl.23.23}
Glossae locorum scripturae et interpretationes nominum
GLOSSAE QUORUMDAM SCRIPTURAE LOCORUM, ET NOMINUM INTERPRETATIONES BRITONUM LINGUA. Ex antiquissimo codice ms. Colbertino, num. 4951.
DE GENESI.


[1553A] {#pl.23.1553a}
DE EXODO. Furfum, dun, vel rot, lege sursum pro furfum. Cervus emissus dicitur quando cervam sequitur. Et equus emissus quando equas sequitur. Fiscellam, sportam thenil. Sponsus sanguinis tu mihi es, id est puer, qui de sanguine meo natus est circumcisus. Non mutiet, grennat, gillit: quia non nocet ei exterminator. Pruinae, brimus. Pretium pudicitiae, id est XII solidos qui ipsam tradidit marito, debet puellae dare. Mittens crabones, id est, urnite, propter terrorem dixit, vel angelos malos. Pelles arietum, id est, sine lana, quasi partica, id est, roth loschi. Pelles jacintinas, id est, sine lana, aut ad tegendum, non est in Britannia. Fibulas, hringan.


[1553B] {#pl.23.1553b}
DE LEVITICO.
DE NUMERIS. Capitium, quod circa collum fithalsetha. Dexteralia, armbo gusbregida ante manicas, et ibi conjunguntur clavi. Renunculi, levint legum. Lumbulos, lenbradun. Chrogillius, animal spinosum major quam hiricius. Garula, rouca. Nuptuam, nectret. Larum, meu. Bononem uuof. Mergulum, niger dicitur a mergendo, id est, dop fugul. Herodianum, uua luc haec fuch brucus similis, id est, locustae, sed major. Aucupio, id est, fugolada. Spatulae, habent similitudinem spadae, inde spadulae dicuntur. Sub pastoris virga transeunt, id est, rabbacula ejus cucurrerunt foras.


[1553C] {#pl.23.1553c}
DE DEUTERONOMIO.
DE JESU NAVE.
DE LIBRO JUDICUM. Signa, id est, pone signum proprium, id est, eribethoon. Uatilla, id est, serscufla similis vasis quibus aqua de navibus projicitur. Bdellium, herba albi coloris est. Aetatis integrae, id est, trigennem. Porfilio, philfor. Noctuorax, nactrafan. Arcuato vulnere, id est, incurvato vulnere: quia cauda scorpionis curva est unde nocet. Postlimenio, id est, post mortem patris. Regulam auream, ringam gurdiles. Civitas litterarum, propter litteratos qui ibidem custodiuntur. Testatio, vel quia ibi fecerunt tistas. Uaum. In taberna, id est, negali sernin.


[1553D] {#pl.23.1553d}
DE RUTH. Sibilos, regum blandimenta. Palantes, fugientes. Litio, id est, eblit. Terafim, id est, idolum. Implevit manum, id est, dedit pecuniam. Congessit polenta, id est, congregatio formal.


[1554A] {#pl.23.1554a}
DE LIBRIS REGUM. Circulum dierum, id est, annum. Focarias, coquinarias, id est, cibum praeparantes. Sitarcis, in quibus cibos portant, id est, fecislun. Unius anni filius, propter humilitatem. Perendie, post cras. Vasa puerorum sancta, id est, corpora, pro persecutione et luxuria. Commentarius, qui scribebat annuales commentarios. Tipsinas, faciunt de hordeo, decorticant ipsa grana in pila, id est, in cavato ligno: deinde coquunt in quo volunt. Ligno lancetico, sicut est biguo, id est, uuidubil. Pilenticus, insanat mentes. Polimitarius, artifex vestimentorum, id est serico, goduu neppi. Abies, arbor mirae altitudinis, unde faciunt tunnas Franci, dicitur sepis. Tornaturas, in transversum, ligno tornata, legge. Celatura dicitur, quod intrat. Sculptura, quod eminet. Anaglippa dicitur quod valde eminet quasi pennae. Istriarum, uualana uuira plectas gumdlunt. Camites quoque cant dicunt. Canis, felgunt. Modioli, nap. Regina Sabaa, id est, Aethiopum. Peltae, longiores sunt, quae scuta nostro tunde. Lecito, vas vitreum in similitudine flasconis, vel panis. Cancellus, id est ligna, subtivitrans versu, vel de foro sicut retr. Elides, affellis. Latrinas cloacas, aquae ductus, id est, groua. Musac sabbati, aedificium ubi miserunt reges munera sabbato, quando ingrediuntur templum. Nam Corban dicitur, ubi erat pecunia sacerdotum. Edra dicitur interior sedes ubi Papa sedet.


[1554C] {#pl.23.1554c}
DE LIRRIS PARALIPOMENON.
DE SALOMONE.
DE ECCLESIASTE. Tignani, qui tigna faciunt, id est, restras. Tafet, nomen templi idoli, vel locifarurum. Allas, groguni. Trullas, panundiufe. Pro octava, id est, novissimo die Azymorum. In fastos, dignitates Panaretus, sapientiam. Coacuerunt, accitaverunt. Aleo, herba est. Blena dicitur, per quam aqua currit. In acervum Mercurii, habent consuetudinem ambulantes in via, ubi Mercurius sepultus est, lapidem jactare in acervum ipsius, unusquisque unum pro honore. Lamuel, agnomen Salomonis, sicut Ecclesiastes ab actione.


[1554D] {#pl.23.1554d}
DE SALOMONIS SAPIENTIA. Contignatium, tectio domus. Capparis, herba est ad cibandum. Fascinatio, laus stulta, id est, mascrunc. Malagma, multa herbae vulneri impositae.
