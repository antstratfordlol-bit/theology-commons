# Sigla — the Schaff Fathers (ANF and NPNF, CCEL)

Minted 2026-08-21 by `99. Tools/patristics/extract_ccel.py`, **one per file**;
resolved into **works** on 2026-08-31 and rewritten in place. This file is
generated from the shelf itself — regenerate it, never edit it.

**815 sigla over 2,841 files**, of which **65 are works
split across more than one file** (2,091 files).
Before the merge the shelf had 2,837 sigla, one per file: the English *City of
God* was 23 separate sigla, the *Confessions* 15, Jerome's letters 142.

**The form is the one `04. Reference/citation-guide.md` §"The Fathers and the
Doctors" prescribes**: `<author-key>-<work-key>`, the author's byname in
English, the work's title in Latin, the leading particle kept (`de`, `in`,
`ad`, `contra`), `v` and never `u`. A collection is one sigla with the number
as the first reference level — `jerome-epistulae.22`, never one sigla per
letter.

**Where the Latin title came from** is in each file's `title-source:`
Latin from the BKV clavis index 44 works,
printed in the file itself 8,
the discipline's standard title 6,
and **757 works keep the English
title the volume prints, because no Latin title was established for them**.
Those are honest gaps, not decisions.

**The reference is what the file prints, never its position.** 1,335 of 1,440
printed numbers disagree with the positional identifier in the ThML source, so
every within-work number here is read from the division title, the running head
or the first body line, and a file that prints no number takes a slug of its
title. `part-ref:` and `part-evidence:` in each file say which and from where.

**The section below the chapter is not anchored.** *Adversus haereses* III, 24, 1
is `irenaeus-adversus-haereses.3.24` and then a quotation: the last level is a
bare numeral inside a paragraph, not a division of the source.

**Author attribution is curated, not read from the files.** The CCEL `author`
field is a division slug, not a person; the names below were assigned by volume
and by slug. Read them as an attribution.

translations are public domain by age.
